# Archive activation

Enable `itpplasma/paper-lean-audit` at https://zenodo.org/account/settings/github/ (Sync now, then On) before publishing the prepared GitHub release. A tag or draft release alone does not create a Zenodo DOI. Record the resulting version DOI in CITATION.cff and the supplementary manifest after the release has actually been archived.

Official workflow: https://help.zenodo.org/docs/github/enable-repository/ and https://help.zenodo.org/docs/github/archive-software/github-upload/ . No Zenodo DOI is claimed for this repository yet.
